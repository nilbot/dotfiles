# Journal

Dated record of what happened: decisions taken, approaches abandoned, runs that
collapsed and why.

`YYYY-MM-DD-<slug>.md`, flat. The date sorts it; the slug says what it was about.
Not named `trace/` — `agents trace` is the machine-bound transcript cache, and
one word must not span two tiers.

Where Q&A answers a question, this answers "what was I doing, and why did it go
that way". See
[knowledge is documentation](../design/2026-08-19-knowledge-is-documentation.md).
