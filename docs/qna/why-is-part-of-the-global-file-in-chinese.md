# Why is part of the global instruction file in Chinese?

## Context

2026-10-01: `global/AGENTS.md` was English with Chinese fragments embedded in it —
the five metaphors inside rule 2, and rule 6's Gaokao standard. The human pointed
at the shape rather than at any one sentence: the file was pieced together from
two languages, so whichever rule was about Chinese arrived through English.

## Answer

The split is by subject.

Rules about **process** stay in English, with the rest of this repository's prose:
no AI attribution, recording what you learn, and the writing rules that are about
references and evidence rather than wording — name things, carry the evidence,
err long, assume the reader has read nothing else. Those rules are the same in
every language, and translating them would buy nothing.

Rules about **Chinese prose** are in Chinese:

| where | what it is |
|---|---|
| `## 语言` | which language to think and reply in, and the sentence that outlaws thinking in one language and translating the reply into another |
| rule 2 | the private metaphors are Chinese words (兜底、锚定、护栏、落点、口径) |
| rule 6 | the standard is a Chinese-language standard: the student who scores 130+ on the Gaokao language paper |

Three reasons, in the order they mattered:

1. It removes a translation hop from the one rule that is about translation.
2. The rule demonstrates the standard it demands. A rule insisting that Chinese
   read like something a person would say cannot itself be translated English —
   which is what it was.
3. The human reads and edits this file. They should not have to translate it back
   into Chinese to judge whether it is right.

Everything else stays English, and a session whose ask arrives in another language
still applies these rules to whichever language it writes in.
