# Q&A

One file per question you would ask again on hitting the same thing. Named for the question, not for the conclusion — a reader arrives with a question.

```markdown
# [The question you would ask when you hit this again]

## Context
[when and why it arose — with the concrete numbers]

## Answer
[the mechanism, with evidence]
```

Filename is kebab-case of the topic. No frontmatter, no schema, no generated index: `ls` is the index and `grep` is the query. Length is set by the finding, never by a rule.

Written when a human says "save that", or when the work hits something worth knowing again.
