# Journal

Dated record of what happened: decisions taken, approaches abandoned, runs that collapsed and why, and retrospective execution notes.

`YYYY-MM-DD-<slug>.md`, flat. The date sorts it; the slug says what it was about.

Implementation plans live in `../plans/`. Where plans describe what we intend to build and Q&A answers specific technical questions, this answers "what was I doing, and why did it go that way".
